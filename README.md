# Weather App

A simple weather application built with HTML, CSS, and JavaScript.

## Features

- Search for weather by city
- Displays temperature
- Displays humidity
- Displays wind speed
- Displays current weather condition
- Supports pressing Enter to search
- Uses Open-Meteo API for weather and location data

## Technologies

- HTML
- CSS
- JavaScript
- Fetch API
- Open-Meteo API

## How to Run

1. Clone the repository
2. Open `index.html` in a browser
3. Search for a city
